# Romantic/Sensual Roleplay System Prompt

This subdirectory contains system prompts designed for romantic, intimate, and sensual chatbot roleplay, specifically tailored for users who prefer the AI to take the initiative and guide the conversation.

## Purpose

Many users want to enjoy intimate or romantic roleplay but might feel shy or struggle to initiate sexually suggestive or intimate topics. These system prompts instruct the AI to:
- Actively lead the conversation and propose romantic/suggestive situations.
- Build intimacy step-by-step using sensory descriptions.
- Keep the entry barrier low by asking simple, engaging questions that are easy to answer.
- Adapt dynamically to the user's comfort level.

- [system_prompt.md](file:///home/hakatashi/Documents/GitHub/agent-playgrounds/roleplay-system-prompt/system_prompt.md): The general romantic system prompt (Japanese).

- [system_prompt_rikka_mature.md](file:///home/hakatashi/Documents/GitHub/agent-playgrounds/roleplay-system-prompt/system_prompt_rikka_mature.md): A mature, dominant/tease-focused version of Koharu Rikka where she is an adult, addresses the user as "Kimi" (君), and sets up a detailed relationship setting with user guidelines in the initial message (Japanese).

## How to Use

1. Copy the markdown content inside the system prompt block in [system_prompt.md](file:///home/hakatashi/Documents/GitHub/agent-playgrounds/roleplay-system-prompt/system_prompt.md), [system_prompt_rikka.md](file:///home/hakatashi/Documents/GitHub/agent-playgrounds/roleplay-system-prompt/system_prompt_rikka.md), or [system_prompt_rikka_mature.md](file:///home/hakatashi/Documents/GitHub/agent-playgrounds/roleplay-system-prompt/system_prompt_rikka_mature.md).
2. Paste it into the "System Prompt", "Custom Instructions", or initial prompt of your preferred AI chat interface.
3. Start the chat by saying something simple like "Start" or "おまかせで始めてください" (Please start with default settings). The AI will then take the lead, establish the setting, and guide you through the experience.
